# Vitalis — Health & Wellness Website

A calm, responsive health and wellness website. Pure HTML, CSS, and vanilla
JavaScript — no build step, no dependencies, no tracking.

## Features

- **Responsive design** — works on phones, tablets, and desktops, with an
  accessible mobile navigation menu.
- **BMI calculator** — metric and imperial units, with a healthy-range guide.
- **Daily water goal** — estimates your target intake from weight and activity.
- **Box breathing** — a guided 4-4-4-4 breathing exercise with an animated ring.
- **Ten habit tips**, a services overview, an about section, and a newsletter
  sign-up (validated client-side).
- **Accessible & private** — skip link, ARIA labels, reduced-motion support,
  and all tools run entirely in your browser. Nothing is sent anywhere.

## Running locally

No build required. Either open `index.html` directly, or serve the folder:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```
